# AGENTS.md

This repository keeps its canonical agent/contributor guidance in
[`CLAUDE.md`](./CLAUDE.md) — commands, architecture, the brand palette, and key
conventions all live there.

`AGENTS.md` exists so that coding agents which look for this filename by
convention still find their way. **There is no separate content here on purpose:
read [`CLAUDE.md`](./CLAUDE.md).** Keeping a single source of truth avoids the two
files drifting out of sync.

For contribution workflow (setup, scripts, PR checklist) see
[`CONTRIBUTING.md`](./CONTRIBUTING.md); for vulnerability reporting see
[`SECURITY.md`](./SECURITY.md).
